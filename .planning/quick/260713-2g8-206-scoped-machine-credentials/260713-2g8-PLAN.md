<objective>
Ship per-capability machine credentials (issue #206 [AI-4]): a client-credentials token scoped to `catalog:read` only can list products (200) but cannot create/mutate them (403), while operator/admin flows are untouched. Purpose: least-privilege integration/agent access to the catalog surface; the scope taxonomy is the auth substrate the [AI-1] MCP model (#203) will consume.
Output: combined converter + write-scope gates + realm client scopes/machine client + docs + OpenAPI advertisement. NO DB migration (V51 stays free).
</objective>
