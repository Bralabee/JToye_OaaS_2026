The SAFE helper (V1__base_schema.sql lines 17-34) — note the exception guard wraps ONLY
current_setting, NOT the final `RETURN v::uuid`, so a non-UUID GUC value still raises 22P02
today. V51 must CREATE OR REPLACE it with the cast inside the guard:

```sql
CREATE OR REPLACE FUNCTION current_tenant_id() RETURNS uuid
LANGUAGE plpgsql AS $$
DECLARE
    v text;
BEGIN
    BEGIN
        v := current_setting('app.current_tenant_id', true);
    EXCEPTION WHEN OTHERS THEN
        RETURN NULL;
    END;
    IF v IS NULL OR v = '' OR v = 'default' THEN
        RETURN NULL;
    END IF;
    RETURN v::uuid;   -- <== V51 moves this cast inside an exception guard too
END;
$$;
```
