<objective>
Implement the `BUSINESS_VERIFIED` gate against the free Companies House Public Data API: a `CompaniesHouseClient` that does an HTTP Basic (API key as username) lookup of a company profile behind a `companies-house` circuit breaker, and a `CompaniesHouseGate` that passes when the company is `active`, WAIVES for sole traders / no-record, fails on a dissolved/other status, and falls back to MANUAL_REVIEW on client failure. Registering the gate as a bean auto-plugs it into the 18-02 `GateChainRunner` registry.

Purpose: automate the company-existence check at zero cost while keeping sole traders (who have no Companies House record) onboardable via WAIVED rather than blocking them.
Output: `CompaniesHouseGate`, `CompaniesHouseClient` + profile type, and unit tests using only already-present test dependencies.
</objective>
