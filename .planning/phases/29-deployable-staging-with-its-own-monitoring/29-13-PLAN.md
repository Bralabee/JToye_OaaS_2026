<objective>
Tracer slice, the secret values: populate Key Vault for every name the render and the two operator scripts derive, write-once,
and make the deploy refuse to start half-configured (D-23). Re-keying DSAR_ENCRYPTION_KEY would make every open request's
ciphertext unreadable, so no code path here can overwrite; rotation goes only through docs/runbooks/credential-rotation.md.

The branch's staging-secrets.sh wrote k8s Secrets from an env file and listed 23 values by hand; the salvage audit dropped its
four AWS values (Phase 36). This rewrite targets Key Vault, derives its list, and classifies every object so the generator
cannot invent a value for something the owner must supply.
Output: the writer, the preflight, a populated vault (machine-made values now; owner-supplied Stripe TEST values at the
checkpoint), per-object access for each workload identity.
</objective>
