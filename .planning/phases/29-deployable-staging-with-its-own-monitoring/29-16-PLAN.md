## Trust Boundaries

| Boundary | Description |

| issue tracker -> future scope | A dropped issue is scope that silently disappears |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-16-01 | Information Disclosure | A credential value in a runbook, a commit message or an issue comment | mitigate | GLOBAL_RULE_6 banner; a value-shaped grep with a proven-firing control; prose passed through quoted heredocs so backtick command substitution cannot alter or leak it |
| T-29-16-02 | Repudiation | An issue dropped rather than deferred | mitigate | Every deferral carries a reason AND a revival condition; the counts are asserted equal |
