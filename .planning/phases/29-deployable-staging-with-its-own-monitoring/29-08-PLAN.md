Tracer slice, application-configuration layer of the DPLY-01 path: the measured repo defects that would stop a vendor
login on a perfect estate, each fixed with its own fail direction.

- Blocker E (DB role split never wired in k8s) and the carried DB_SSL_MODE switch (a managed server requires TLS; ASVS V9
  wants it verified).
- Blocker A (`keycloak.client-id: "frontend"` names a client the realm does not have) — fixed at the base, because the
  base value is wrong for every environment; plan 26-08's "byte-identical" rationale preserved a broken value.

  schedule on 3 × B2s).
- Pitfall 4 (one shared TLS secret for api+app = one ACME order; a failed challenge fails both) and the latent second
  defect it hides: the SSE Ingress requests a certificate into the same Secret as the main Ingress, so two cert-manager
  Certificates would fight over it. Plus D-08 applied to crawlers (noindex on staging) and D-29's annotation coverage.

Output: the fixes, INV-14, INV-15, one new unit test, regenerated goldens and metrics.
