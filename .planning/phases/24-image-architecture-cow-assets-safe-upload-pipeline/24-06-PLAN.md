| Boundary | Description |
|----------|-------------|
| authenticated vendor → dashboard review UI | Dashboard is authenticated (SEO N/A); the queue shows only the caller's tenant assets (RLS at the API) |
| storefront `<img>` → public | The rendered derivative URL is public; must keep crawlable `<a>`/`<img>` + `alt` (D-07) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-23 | Information Disclosure | review-queue data in the browser | mitigate | The queue fetches the tenant-scoped `/api/v1/media/review-queue` (RLS-isolated backend, 24-05); the client renders only what the API returns |
| T-24-24 | Tampering | Replace re-upload without idempotency | mitigate | Replace sends a fresh `Idempotency-Key` to the accept endpoint (24-03 contract) — a double-submit does not duplicate an asset |
| T-24-25 | Information Disclosure (SEO/web-perf regression) | storefront image render | mitigate | `AssetImage` preserves `alt` (only present SEO surface; JSON-LD baseline null) and sets explicit width/height on the WebP derivative (CWV, D-07); no `next.config` change |
</threat_model>
