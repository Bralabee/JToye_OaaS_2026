## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client localStorage → shop selection | a per-device UI preference, NOT a trust boundary — the server re-validates every grant on every request (D-07) |
| switcher shop list → visible shops | must reflect only the read-scoped server list, never a client-invented set |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-05-01 | Elevation | tampering localStorage to select a forbidden shop | accept/mitigate | Not a trust boundary — every shop-scoped request is re-validated by ShopAccessService (23-03); a forbidden selection yields a typed 403 rendered as access-required (D-13) |
| T-23-05-02 | Elevation | non-GA sees/triggers the group-wide "apply to all" action | mitigate | apply-to-all rendered only for GA in the "All shops" context (D-08); the server also gates group-wide writes to GROUP_ADMIN |
| T-23-05-03 | Information disclosure | switcher lists shops the caller has no grant on | mitigate | switcher source is the read-scoped GET /api/v1/shops (23-03) — it structurally cannot list ungranted shops |
| T-23-05-04 | Denial of service (UX) | 375px overflow/occlusion regression | mitigate | 375px Playwright + Jest assertions; live human-verify checkpoint |
