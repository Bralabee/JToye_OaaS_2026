Ship the GROUP_ADMIN-only staff-management REST backend (VSA-04): list the login-populated
directory + current grants, grant a `(user, shop|null, role)`, and revoke a grant — with the
last-GROUP_ADMIN 409 guard (D-11) and immediate revocation via membership-cache eviction (D-05).

(out of scope). This is a Wave-3 sibling of 23-03 with zero file overlap — both depend only on
`ShopAccessService` (23-02) and neither modifies it.

Purpose: This is the write side of the access model — the screen (23-06) calls these endpoints so a
GROUP_ADMIN can genuinely scope staff, and a grant/revoke takes effect on the target's very next
request with no stale window.

Output: `StaffController` + `StaffManagementService` + record DTOs + `StaffManagementIntegrationTest`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → staff-management endpoints | only a GROUP_ADMIN (or realm-admin) may list/grant/revoke |
| revoke → target's cached membership | eviction must land before the target's next request |
| final GROUP_ADMIN → self-removal | must be blocked to avoid tenant-level lockout |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-04-01 | Elevation | non-GROUP_ADMIN grants/revokes staff | mitigate | requireGroupAdmin() at the top of every service method; Task 2 non-GA→403 |
| T-23-04-02 | Denial of service (self) | last-GROUP_ADMIN lockout | mitigate | 409 guard on revoke/downgrade (D-11); realm-admin recovery backstop; Task 2 last-GA→409 |
| T-23-04-03 | Elevation | stale-grant window after revoke | mitigate | evictMembership after commit (D-05); Task 2 revoke→immediate 403 |
| T-23-04-04 | Tampering | client-supplied role/shop escalates beyond intent | mitigate | grant writes only the validated (userId, shopId, role) under RLS; role constrained by enum + DB CHECK |
| T-23-04-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (RESEARCH Package Legitimacy Audit: N/A) |
</threat_model>
