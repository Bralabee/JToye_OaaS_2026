<objective>
Build the enforcement engine `ShopAccessService` and its typed error contract. This service is
the single seam every shop-scoped write and read-scope call in 23-03 uses, and the last-GROUP_ADMIN
409 type 23-04 throws. It composes proven internal parts: a per-user membership cache
(`TenantAwareCacheKeyGenerator` + evict via `TenantCacheEvictor`), the realm-admin ⇒ implicit
GROUP_ADMIN bridge (reads the existing `ROLE_admin` authority), D-04 JIT lazy-provision
(race-safe `INSERT ... ON CONFLICT DO NOTHING` on first request), the D-09 throttled directory
upsert, and the D-12 strict-scoping switch. Add two typed errors — `ShopAccessDeniedException`
(403 with a **distinct** `type` URI from the RLS 404 and the generic /forbidden 403) and
`LastGroupAdminException` (409) — wired into `GlobalExceptionHandler`.

Purpose: Concentrate all authorization decisions in one tested unit before spraying `require()`
calls across the service layer (23-03). Interface-first: the API surface below is the contract
23-03 and 23-04 code against.

Output: `ShopAccessService` + `Membership` value type + two exceptions + handler additions +
config keys + JIT-idempotency and error-type-distinctness tests. No `require()` calls inserted
into domain services yet (that is 23-03).
</objective>

ShopAccessService (@Service @Transactional):
  - void require(UUID shopId, ShopRole minRole)
        // throws ShopAccessDeniedException(shopId, minRole) if the caller lacks minRole on shopId.
        // realm-admin ⇒ allow. Runs JIT-provision on first require() of the request (strict-scoping OFF).
  - void requireGroupAdmin()
        // throws ShopAccessDeniedException if caller is neither realm-admin nor a GROUP_ADMIN row.
  - boolean isGroupAdmin()          // true for realm-admin or a tenant-wide GROUP_ADMIN grant
  - Set<UUID> grantedShopIds()      // shop_ids the caller may read; empty for a fully-ungranted user in strict mode
  - Membership resolveMembership(UUID userId)   // @Cacheable("shopMembership"); source of the two above

Membership (value type): isGroupAdmin flag + Map<UUID shopId, ShopRole> perShopRole (tenant-wide grant → isGroupAdmin true).

Config keys (application.yml, all profiles inherit base):
  - jtoye.access.strict-scoping           (${ACCESS_STRICT_SCOPING:false})   // D-12, default OFF
  - jtoye.access.directory-upsert-interval (${DIRECTORY_UPSERT_INTERVAL:PT1H}) // D-09 throttle window
