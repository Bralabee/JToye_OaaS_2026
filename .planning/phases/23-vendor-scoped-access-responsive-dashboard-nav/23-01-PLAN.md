    Create `V52__shop_staff.sql`. Three tables, all idempotent (`CREATE TABLE IF NOT EXISTS`,
    policy creation wrapped in the V43-style `DO $$ ... IF NOT EXISTS (SELECT 1 FROM pg_policies ...) $$`).

    (1) `shop_staff`: columns `id UUID PRIMARY KEY`, `tenant_id UUID NOT NULL`,
    `user_id UUID NOT NULL` (Keycloak sub), `shop_id UUID REFERENCES shops(id)` (NULL = tenant-wide
    GROUP_ADMIN shape), `role VARCHAR(16) NOT NULL CHECK (role IN ('GROUP_ADMIN','SHOP_MANAGER','STAFF'))`,
    `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`, `created_by UUID`. Uniqueness is a **functional
    UNIQUE INDEX** `uq_shop_staff_tenant_user_shop ON shop_staff (tenant_id, user_id, COALESCE(shop_id,
    '00000000-0000-0000-0000-000000000000'::uuid))` — a table UNIQUE constraint cannot use COALESCE.
    Add `idx_shop_staff_tenant_user (tenant_id, user_id)` and `idx_shop_staff_shop (shop_id)`.
    `ENABLE` + `FORCE ROW LEVEL SECURITY`; policy `shop_staff_tenant_policy FOR ALL
    USING (tenant_id = current_tenant_id()) WITH CHECK (tenant_id = current_tenant_id())`.

    (2) `shop_staff_aud` (Envers mirror): all columns nullable, `PRIMARY KEY (id, rev)`,
    `rev INT NOT NULL REFERENCES revinfo(rev)`, `revtype SMALLINT`. `ENABLE`+`FORCE`; policy predicate
    ADMITS NULL tenant_id: `USING (tenant_id IS NULL OR tenant_id = current_tenant_id())` and same
    WITH CHECK (V51/V43 refunds_aud pattern).

    (3) `user_directory` (D-09): `tenant_id UUID NOT NULL`, `user_id UUID NOT NULL` (sub),
    `email VARCHAR(320)`, `display_name VARCHAR(255)`, `last_seen TIMESTAMPTZ NOT NULL DEFAULT now()`,
    `PRIMARY KEY (tenant_id, user_id)`. `ENABLE`+`FORCE`; policy `user_directory_tenant_policy FOR ALL
    USING (tenant_id = current_tenant_id()) WITH CHECK (tenant_id = current_tenant_id())`. NO `_aud`.

    Every USING/WITH CHECK uses `current_tenant_id()` — NEVER `current_setting('app.current_tenant_id',
    true)::uuid`. Do NOT write any GROUP_ADMIN row here (§1-FLAG: no migrate-time backfill exists; the
    tables ship empty; JIT provisioning in 23-02 fills them on first request).
