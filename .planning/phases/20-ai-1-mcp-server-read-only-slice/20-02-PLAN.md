| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-20-03 | Elevation of Privilege / Info Disclosure | read_orders cross-tenant id | mitigate | A tenant-A caller reading a tenant-B order id resolves to core RLS → 404/empty; MCP picks no tenant. Proven end-to-end in 20-05 e2e-rls.sh. |
| T-20-04 | Tampering / Info Disclosure | read-orders path building | mitigate | shopId/orderId interpolated into allow-listed path templates only; base URL fixed; agent cannot choose the host (SSRF guard). |
</threat_model>
