- P-1: a kustomization's `replicas:` list applies ONLY to Deployment/ReplicationController/
  ReplicaSet/StatefulSet. It does NOT touch HorizontalPodAutoscaler or PodDisruptionBudget, so
  D-09's three targets need two mechanisms.
- P-2: ONE multi-document strategic-merge patch file, referenced once as
  `patches: - path: scale-patch.yaml`, correctly targets all six objects by GVK+name. Verified
  result: `replicas: 1` x3, `minAvailable: 1` x3, `minReplicas: 1` x3, `maxReplicas` 10/20/10
  UNCHANGED. No JSON6902 patch is needed.
- P-3: a strategic-merge patch on `app-config` MERGES the listed keys into the base's data map; it
  does not replace `data`. So the local patch lists only what changes.
- P-4: on an Ingress, `rules:` has no patch merge key, so supplying `rules:` REPLACES the whole
  list; `annotationKey: null` DELETES that annotation; `tls: null` deletes the whole TLS block.

  explicit `fields:` shape plan 26-01 applied to base/staging/production, or the local render

Blockers that must be handled in this overlay:
- PIT-1 (HIGH): minikube v1.36.0 bundles ingress-nginx **v1.12.2**, where
  `allow-snippet-annotations` defaults to `false` and `annotations-risk-level` to `High`. The
  `nginx.ingress.kubernetes.io/configuration-snippet` annotation on `k8s/base/ingress.yaml:29-35`
  is therefore REJECTED by the validating admission webhook. Null it in the LOCAL patch only. Do
  NOT enable snippet annotations on the cluster and do NOT remove the security headers from base —
  that would trade away a production good.
- PIT-10 (LOW): `limit-rps: 100`, `limit-burst-multiplier: 5`, `limit-connections: 50` on the base
  ingress can throttle a Playwright run from a single source IP. Null all three in the local patch.
- No `commonAnnotations: deployment.timestamp` in this overlay: staging/production stamp
  `REPLACE_WITH_DEPLOYMENT_TIMESTAMP` at deploy time, local has no CI stamp step, and
  `check-no-plaintext-secrets.sh` exempts only that exact annotation — an unstamped placeholder
  would fail the gate.
- `secretGenerator` is FORBIDDEN here: it emits `kind: Secret`, and
  `check-no-plaintext-secrets.sh` auto-discovers `k8s/local` at `maxdepth 2`. Secrets arrive
  out-of-band from plan 26-05's bootstrap script (D-01).
