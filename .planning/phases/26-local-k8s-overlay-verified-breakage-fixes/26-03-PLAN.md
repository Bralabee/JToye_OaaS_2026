1. Injected-env extraction — `k8s/base/core-java-deployment.yaml`, anchored to the env-list item
   indent: `^\s+- name: ([A-Z0-9_]+)\s*$`. Verified to yield exactly 23 names before plan 26-02's
   additions.
2. Placeholder extraction — all `core-java/src/main/resources/application*.yml`. The regex MUST
   tolerate one level of nesting: `\$\{([A-Z0-9_]+)(?::((?:[^{}]|\$\{[^}]*\})*))?\}`. A naive
   `\$\{([A-Z_]+):([^}]*)\}` mis-terminates on the two real nested defaults at
   `application.yml:142` (`${JWT_EXPECTED_ISSUER:${spring.security...issuer-uri}}`) and
   `application.yml:154` (`${CUSTOMER_JWT_EXPECTED_ISSUER:${jtoye.security.customer-jwt.issuer-uri}}`),
   plus the four STOMP chains plan 26-01 added. Requires GNU `grep -P`; exit 2 if unavailable.
3. The uppercase filter IS the env-vs-property discriminator. `${spring.application.name}` and
   `${jtoye.security...}` are Spring property references, not env vars; `[A-Z0-9_]+` excludes them
   with zero false positives across the 116 results research enumerated.
4. Profile scope: scan ALL `application*.yml`. Verified that the set of placeholders appearing only
   in `-dev`/`-test`/`-local` is EMPTY, so scanning all six files gives the same 116-name set as
   scanning base+prod+staging — and no dev-only allowlist entries are needed.
5. One name can have SEVERAL different defaults across profiles (real cases: `DB_POOL_SIZE`
   `10`|`20`; `RABBITMQ_USER` `jtoye`|`guest`; `CUSTOMER_JWT_REQUIRE_VERIFIED_EMAIL` `false`|`true`;
   `REDIS_PASSWORD` no-default|empty). Collect a SET of defaults per name and trip the local-only
   rule if ANY member matches — matched per-default, never on a joined string (a `^guest$`-anchored
   test against the joined `jtoye|guest` string misses it).
6. Spring-native env names are not `${}` placeholders and belong on the direction-(a) allowlist:
   `SPRING_PROFILES_ACTIVE` today, and if ever added `MANAGEMENT_ENDPOINTS_WEB_EXPOSURE_INCLUDE`,
   `JAVA_OPTS`, `TZ`.
7. Bare-word local defaults matter as much as URLs. The word list is `localhost`, `127.0.0.1`,
   `0.0.0.0`, `minioadmin`, `guest`, `mailhog`, `host.docker.internal` — `${RABBITMQ_USER:guest}`
   and `${S3_ACCESS_KEY:minioadmin}` are the DEF-4 / DEF-6 signature and a URL-only regex misses both.
