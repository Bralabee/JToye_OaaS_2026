<objective>
Replace MinIO with a digest-pinned Azurite in every local runtime and in the nightly's service
list, give the hybrid runtime its own Azurite (D-08), and remove every object-store credential
from the env contract.

Purpose: MinIO's images are gone (quay 401 since ~2026-09-24, the cause of #683), so the compose
stack cannot start today. This plan removes that cause rather than working around it.

Output: compose, hybrid compose, horizons row, nightly SERVICES, env contract, and the hybrid
start script. Nothing here starts core-java.
</objective>

--disableProductStyleUrl (load-bearing for k8s/local, where host.minikube.internal contains a dot),

feature fails at runtime instead of at the version check -- record it), --disableTelemetry.

and supplies the emulator key itself (verified in bytecode).
