<objective>
Build blobctl, the small Go uploader the pg-backup image will use instead of the AWS CLI, with the
same one-switch auth model as core-java and an emulator-only connection-string path.

Purpose: BLOB-06. The Go SDK does not understand UseDevelopmentStorage=true (verified in
azblob v1.8.1's shared.go), azcopy authenticates to Azurite only with a SAS, and the Azure CLI would
put ~700 MB of Python into a Postgres image. A tiny purpose-built CLI is the smallest trusted
surface for a job that holds database credentials.

Output: a tested Go module under infra/backups/blobctl, its CI and Dependabot wiring, and a
targeted gitleaks allowlist proven in both directions. The image that ships it is 36-08.

Design choice (Claude's discretion on the seam, recorded): blobctl parses the SAME emulator
connection-string form core-java uses (UseDevelopmentStorage=true with an optional
DevelopmentStorageProxyUri), and derives the endpoint the way the Java SDK does
(<proxy-or-127.0.0.1>:10000/devstoreaccount1). So k8s/local, compose and the drill pass one
identical string to both programs and no Secret carrying a key is needed anywhere.
</objective>

  <behavior>
    Cases (input -> expected):
    - STORAGE_AUTH_MODE unset -> error naming "connection-string" and "workload-identity"
    - STORAGE_AUTH_MODE=bogus -> error naming the two allowed values
    - workload-identity, STORAGE_ENDPOINT=https://jtoyestgbackup.blob.core.windows.net + AZURE_CLIENT_ID/AZURE_TENANT_ID/AZURE_FEDERATED_TOKEN_FILE set -> Config{Mode: WI, Endpoint: that URL}
    - workload-identity with endpoint http://x.blob.core.windows.net or https://evil.example.com -> error
    - workload-identity with any one of the three AZURE_* vars missing -> error naming the missing var
    - connection-string, STORAGE_CONNECTION_STRING=UseDevelopmentStorage=true -> endpoint http://127.0.0.1:10000/devstoreaccount1
    - connection-string, UseDevelopmentStorage=true;DevelopmentStorageProxyUri=http://azurite -> endpoint http://azurite:10000/devstoreaccount1
    - connection-string, ...;DevelopmentStorageProxyUri=http://host.minikube.internal -> endpoint http://host.minikube.internal:10000/devstoreaccount1
    - connection-string with AccountName=realacct;AccountKey=<anything> or SharedAccessSignature=<anything> -> error containing "emulator-only"
    - Config's String() never contains the emulator key, a token path's file contents, or the connection string
  </behavior>
  <implementation>LoadConfig(env func(string) string) (Config, error) in config.go; NewClient(Config) builds azblob clients; emulator.go holds the one key constant; commands.go holds upload/list/download over an interface so commands are unit-testable with a fake.</implementation>
