<objective>
Make every storage misconfiguration fail loudly at startup, in every runtime, and assert the #626
container access levels on every boot.

Purpose: D-02 ("a misconfiguration must fail fast at startup, not at first upload") and D-08 (the
check stays ON in every runtime). Two rules deviate from 36-RESEARCH.md Pattern 1, deliberately:
(1) the research refused connection-string mode when profile prod/staging is active, but
k8s/local runs profile prod (k8s/base/core-java-deployment.yaml:64-65, local keeps it on purpose),
so a profile rule would break k8s/local; the rule here refuses any NON-EMULATOR connection
string in every profile, which is strictly stronger for D-02. (2) validate-on-startup is not
env-mapped, so no runtime can switch it off by environment.

Output: shape validation with a failing test per rule, the credential-build proof for A1, the
startup probe with Azurite arms, and test-context hygiene proven across the full suite.
</objective>

    - authMode "connection-string", connectionString "UseDevelopmentStorage=true" -> valid

    - authMode "connection-string", "DefaultEndpointsProtocol=http;AccountName=devstoreaccount1;AccountKey=<x>;BlobEndpoint=http://h:10000/devstoreaccount1" -> valid (Testcontainers' form)
    - authMode "connection-string", AccountName other than devstoreaccount1, or a SharedAccessSignature -> StorageConfigurationException containing "emulator-only"
    - authMode "connection-string", blank string -> exception naming STORAGE_CONNECTION_STRING
    - authMode "bogus" or blank -> exception naming both allowed values
    - authMode "workload-identity", endpoint https://jtoyestgmedia.blob.core.windows.net, the three AZURE_* env present -> valid
    - authMode "workload-identity", endpoint http://... or https://example.com -> exception
    - authMode "workload-identity", any one AZURE_* env missing -> exception naming it
    - authMode "workload-identity", createContainers true -> exception ("Set Container ACL cannot be authorized with Entra ID")
    - container name "Jtoye_Images", "a", "ab--cd", or publicContainer == quarantineContainer -> exception
    - publicUrl "http://localhost:10000/devstoreaccount1/other" with publicContainer jtoye-images -> exception
    - maxTries 0 or tryTimeoutSeconds 0 -> exception
    - Probe: public BLOB + quarantine PRIVATE -> passes; public CONTAINER -> exception mentioning #626; quarantine BLOB -> exception; a missing container with createContainers false -> exception; createContainers true on empty Azurite -> creates both with the right levels then passes
  </behavior>
