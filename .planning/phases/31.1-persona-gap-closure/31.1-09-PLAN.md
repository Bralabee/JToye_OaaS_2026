<objective>
Put the recorded allergen set on every customer-facing order contract (#785 data half, D-08; D-07's channel).

Purpose: no confirmation, tracking response or history entry carried any allergen field, so a
customer could never see what was recorded, and a vendor-entered order was indistinguishable from
one the customer acknowledged. This plan exposes the acknowledged set (order columns) and the
recorded set (V63 snapshot) as separate fields on the confirmation, tracking, history, list and
detail DTOs. The UI that renders them is 31.1-15 (confirmation) and 31.1-18 (tracking, My Orders);
the email is 31.1-25.

Output: DTO fields, the mapper and service wiring, an integration test with an N+1 guard, the
regenerated OpenAPI snapshot and the extended Phase 38 contract.
</objective>
