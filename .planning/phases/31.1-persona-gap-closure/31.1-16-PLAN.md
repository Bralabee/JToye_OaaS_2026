## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker -> every tenant | cross-tenant reach exists only through the tenant loop + pinned GUC |
| email link -> anonymous holder | possession of the token is the only credential for a cross-tenant personal-data document |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-31.1-56 | Information disclosure | export store read in a database dump | high | mitigate | Payload encrypted (ACCESS_EXPORT purpose, request-id AAD); token stored as SHA-256 only |
| T-31.1-57 | Information disclosure | cross-tenant leakage inside the export | high | mitigate | Per-tenant transaction with pinned GUC and explicit tenant predicates; GUC-pin break arm |
| T-31.1-58 | Information disclosure | personal data in the email | high | mitigate | Link only; body assertion against fixture PII |
| T-31.1-59 | Spoofing | link forwarded or intercepted | medium | mitigate | Single use, 7-day expiry, token in the URL fragment (never sent to a server in a request line), sent only to the verified address |
| T-31.1-60 | Repudiation | request marked complete without delivery | medium | mitigate | COMPLETED only after store + successful send; mail-failure break arm |
| T-31.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installed |
</threat_model>
