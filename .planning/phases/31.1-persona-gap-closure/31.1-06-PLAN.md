<objective>
Stop a product whose own ingredients name an allergen from passing silently as allergen-free (#787 P0, D-09 backend).

Purpose: the vendor typed "rice, butter (MILK), pepper", ticked nothing, and the storefront said "No
allergens". Reconciliation exists only at order time and only over `**...**` spans, so the persona's
capitalised MILK was never seen. This plan extends the one existing parser to capitals (FSA lists
capitals as valid emphasis), returns a typed warning on save, and exposes the disagreement on every
product DTO so the vendor and storefront surfaces (31.1-19, 31.1-21) can render it.

Output: an emphasis-aware aggregator, typed save warnings, a public flag field, the acceptance IT,
the OpenAPI snapshot and Phase 38's DTO contract extended.
</objective>
