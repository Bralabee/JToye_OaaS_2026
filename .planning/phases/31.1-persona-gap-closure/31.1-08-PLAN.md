<objective>
Wire the D-19 encryption key into every runtime that starts core-java, so the fail-fast boot from
31.1-07 never meets a runtime without a key.

Purpose: after 31.1-07, core-java does not start without `DSAR_ENCRYPTION_KEY`. Compose, the hybrid
runtime, the nightly and every k8s overlay start core-java; each must supply a real key from a secret
and none may carry a literal.

Output: compose + .env.example + verify-env, start-dev, the nightly's ephemeral key, the k8s Secret
reference, template and local bootstrap, regenerated goldens, and the env-contract gate green.
</objective>
