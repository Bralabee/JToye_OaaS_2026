## Decisions Made

- **The test key is random only.** The plan said the test profile key should "default to" two random values. It is NOT routed through `DSAR_ENCRYPTION_KEY`, so a developer shell exporting a real key cannot leak it into tests. The "two reads differ" assertion also depends on this.
- **The address is stored as typed and trimmed, not lower-cased.** It is a mailbox, not a match key. Matching stays digest against digest (V62 is unchanged).
- **R-14's period is honest about its scope.** 168 hours bounds an unconfirmed request only. A confirmed request is held until answered. Expiry lands within one 15-minute sweep interval of the window.
- **The ACCESS backlog is unchanged.** ACCESS requests now also store the ciphertext, ready for 31.1-09/-10 (D-01). They are still only counted by the worker, and they reach a terminal state (and a NULL) only through expiry until ACCESS execution lands.
