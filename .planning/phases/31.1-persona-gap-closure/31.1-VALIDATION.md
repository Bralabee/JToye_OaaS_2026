---

## Sampling Rate

- **After every task commit:** run that task's quick/unit command.
- **After every plan wave:** `./gradlew :core-java:test`, plus the wave's integration classes, plus `npx jest`, plus `npm run build` (jest does not type-check).
- **Before `/gsd-verify-work`:** full suite green, then the static gates (`scripts/docs-freshness.sh`, `scripts/check-doc-metrics.sh`, `scripts/check-openapi-snapshot-fresh.sh`, `scripts/check-ssr-coverage-contract.sh`, `scripts/check-retention-enforcement.sh`, `scripts/check-no-create-extension.sh`, `k8s/scripts/check-env-contract.sh`, `scripts/check-gate-enforcement.sh`, `scripts/check-branch-behind-base.sh`), then rebuild ALL images, `scripts/check-runtime-freshness.sh`, and a Playwright click-through on the live stack.
- **Max feedback latency:** 30 s for unit/jest; Testcontainers classes run per plan, not per task.
- **Fail direction:** every row below is run on the pre-fix tree first and its red output recorded beside the green. Commit before break arms; verify restores by content.
