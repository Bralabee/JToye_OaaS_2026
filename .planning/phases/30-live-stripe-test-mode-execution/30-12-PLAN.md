<objective>
PAY-03 prerequisite, PR 4 part 1 of 4 — the Connect webhook. Branch: `feat/30-connect-webhook` (cut in plan 30-11).

Stripe delivers Express `account.updated` and every direct-charge `payment_intent.*` / `refund.*` event only to a
"Connected accounts" endpoint, which has its own signing secret (30-RESEARCH § PAY-03 blocker, docs.stripe.com/connect/webhooks).
The code verifies against one secret, so the staging tenant can never reach ENABLED and neither settlement mode can occur
on staging. This plan adds the second route and secret, keeps one dispatcher, makes events from other environments sharing
the Stripe account harmless, and requests the Express capabilities explicitly so onboarding can reach charges_enabled.
Platform wiring (Key Vault, SPC, env) is plan 30-13; the owner registers the endpoint in plan 30-14.
Output: the route, the second secret, environment tagging and acks, capabilities, tests.
</objective>
