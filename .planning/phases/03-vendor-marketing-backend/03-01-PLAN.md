## Threat Model (ASVS Level 1)

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Cross-tenant promotion access | HIGH | RLS policy on shop_promotions with correct GUC name (app.current_tenant_id). Fix V28 bug in same migration. |
| Negative discount amounts | MEDIUM | Jakarta validation: @Min(1) on discountPercent, @Min(1) on discountAmountPennies |
| Discount type bypass (both fields set) | MEDIUM | @AssertTrue custom validation enforcing mutual exclusivity |
| SQL injection via Flyway | LOW | Static DDL/DML only, no dynamic input |
</threat_model>
