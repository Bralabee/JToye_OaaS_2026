<objective>
Give each shop its own figures and an export, without opening the tenant ledger to non-admins (RWO-027 UXT-027; roadmap SC-2).

Purpose: today per-shop finance shows tenant totals and a site manager's 403 renders as "No financial data yet". Ledger rows
carry no shop. This plan adds shop_id (with a safe backfill), scoped reads with the right gate, and a CSV export of exactly the
scope shown.

Output: V79 + stepwise test, shop-aware writers, scoped summary/list/export, the IT, the OpenAPI snapshot.
</objective>

Noun now primary: per-shop finance scope, alongside the tenant-wide ledger view.
Decision: add-alongside — shop_id is nullable; tenant-wide totals stay the Group-admin view and include rows with no shop.
Accepted debt: rows with a NULL shop (MANUAL entries, legacy order-less rows) are visible only tenant-wide, so per-shop totals need
not sum to the tenant total. What would force a promote: a requirement that every pound is attributed to a shop (multi-entity
accounting or per-shop VAT returns) — then shop_id becomes NOT NULL with an explicit tenant-level bucket.
Suggested invariant test: sum over shops of shop totals + the NULL-shop bucket == tenant total, for a seeded multi-shop tenant.
