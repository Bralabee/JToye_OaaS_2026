<objective>
Make the test suite able to prove D-06 (strict scoping ON by default) before the default flips.

Purpose: 11 test classes flip the strict-scoping singleton by reflection and reset it to a literal `false`, which silently
re-arms OFF for every later class sharing the cached context; a green suite after the flip would prove nothing. This plan
fixes that leak, adds the explicit-grant helper, and enumerates every red under strict ON so 37-03 can convert them and
37-04 can flip with a green suite (RWO-004 UXT-004, RWO-003 UXT-003).

Output: two test helpers, one booted-value instrument, 11 teardown fixes, and the strict-ON red list.
</objective>
