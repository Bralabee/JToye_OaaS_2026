<objective>
Make "who can do what" a server-computed fact the Staff page can show, and prove revoke ends access (D-08, D-09; RWO-003
UXT-003, RWO-004).

Purpose: the Staff page today reconstructs access in the browser from raw rows (theme 2), ungranted users who only read never
appear, a realm admin would read "No access", and a "role + all shops" grant confers nothing. This plan computes effective access
in `ShopAccessService`, records directory rows on reads, honours tenant-wide non-admin roles, and proves UXT-003 with the
revoked user's own token.

Output: V76, EffectiveAccess, the read-path directory toucher, the people list, the UXT-003 arm, the regenerated OpenAPI snapshot.
</objective>
