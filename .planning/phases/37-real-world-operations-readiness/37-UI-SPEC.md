## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Tailwind | Usage in this phase |
|-------|-------|----------|---------------------|
| xs | 4px | `1` | Icon-to-text gap inside badges and pills |
| sm | 8px | `2` | Badge rows on a kitchen card, list-item gaps, gap between the bump button and the print button |
| md | 16px | `4` | Default element spacing, card padding on mobile, page gutter ≤640px |
| lg | 24px | `6` | Section spacing (`space-y-6`, as every dashboard page), card padding ≥640px |
| xl | 32px | `8` | Gap between the New lane and the board grid; between the invite page's sections |
| 2xl | 48px | `12` | Vertical padding of empty states (`py-12`, as the webhooks empty state) |
| 3xl | 64px | `16` | Vertical padding of standalone pages (B2, B3) |

**Exceptions (each is a measured constraint, not a rounding accident):**

| Exception | Value | Why |
|-----------|-------|-----|
| Minimum touch target | **44 × 44 px** (`h-11`, `min-h-11`) | The shadcn default `h-10` measured 40 × 40 on a 375px iPhone SE profile (`kitchen/page.tsx:1022-1026`). This applies to every new control on every surface in this phase, including table-row actions and checkboxes (24px box inside a 44px label row). |
| Board-stopped overlay buttons | **56px** tall (`h-14`), full width up to 384px (`max-w-sm`) | Pressed by a gloved hand on a wall-mounted screen while an alarm sounds. This is the one place a missed tap costs a service. |
| New-order flash ring | **4px** (`ring-4`) | The thinnest ring that reads at 1.5 m. The existing 2px age border sits inside it and must stay visible. |
| Existing checkout CTA padding | `py-3.5` = 14px | Pre-existing (`checkout/page.tsx:1286`). Recorded, not changed. |

**There is no 12px token.** Every block this phase introduces pads in 8px and 16px steps (for
example the customer note `px-4 py-2`, the paused banner `p-4`, the finance scope banner
`px-4 py-2`). Off-scale padding that already exists on surfaces being extended (`py-3.5` above,
`px-3 py-2` inside the Phase 31/31.1 allergen and allergy-note blocks) is pre-existing, and is
neither copied nor changed.
| Safe-area inset | `env(safe-area-inset-bottom)` | The sticky bulk-reject action bar (D1) and the cookie banner (F5) are bottom-fixed. |

## Typography

Base scale for **everything this phase introduces**: 4 sizes, 2 weights.

| Role | Size | Weight | Line Height | Tailwind | Used for |
|------|------|--------|-------------|----------|----------|
| Label / compact body | **14px** | 400 body, 600 label | 1.43 (20px) | `text-sm`, `text-sm font-semibold` | Dashboard tables, forms, checkout panels, kitchen card text, every badge and pill |
| Body | **16px** | 400 | **1.5** | `text-base leading-normal` | Standalone page body (B2, B3), kitchen customer note, board-stopped body, storefront availability notice |
| Heading | **24px** | 600 | **1.25** | `text-2xl font-semibold leading-tight` | Standalone page `<h1>` (B2, B3, same as the data-request token pages), the kitchen "New orders" lane heading |
| Display | **36px** | 600 | **1.1** | `text-4xl font-semibold` | The new Developers page `<h1>` (matches the `text-4xl` used on nine dashboard pages, at the 600 weight `onboarding` and `approvals` already use) and the board-stopped headline |

**Two weights only: 400 and 600.** Weight 700 is **barred from every component this phase
introduces**.

**Inherited, not overridden.** Every value in this table is **grandfathered on the exact element
named, and only there.** None may be copied onto a component this phase introduces. A new
component that uses `font-bold`, a 20px size, or `font-medium` outside the `Button` and
`DialogTitle` primitives breaks this contract. Whether to retire these legacy values is an
**owner decision, flagged here and not taken by this phase**: retiring them would restyle surfaces
the persona testers praised (P2-FUN-18, P2-CHA-15).

| Inherited value | Where | Why it stays |
|-----------------|-------|--------------|
| `font-medium` (500) | `Button` primitive base class (`components/ui/button.tsx`) | A design-system primitive used by every button in the product. Overriding it per new button would make new and old buttons differ. |
| `DialogTitle` primitive's built-in size | `components/ui/dialog.tsx` | Same reasoning: dialogs must match the product's existing dialogs |
| `text-4xl font-bold` page titles | Kitchen, Staff, Finance, Orders, Products, Shops pages | Grandfathered on pages this phase **extends**. Extending a page is not licence to restyle its title. |
| 20px/600 "ALLERGENS" label, allergy-note label | `OrderAllergenBanner`, `AllergyNoteBlock` | Phase 31/31.1 contract; untouched |
| `font-bold` totals and the "Place order" label | `checkout/page.tsx` | Pre-existing on an extended surface |

**Per-surface overrides:**

| Surface | Override | Reason |
|---------|----------|--------|
| K1 card: fulfilment badge, unverified badge | 14px/600, `uppercase tracking-[0.08em]` for fulfilment only ("DELIVERY" / "COLLECTION") | It is a two-value code read at 0.6-1.5 m. The unverified badge stays sentence case, because it is a caution, not a code. |
| K1 card: customer note | Label "NOTE FROM CUSTOMER" 14px/600 uppercase; note text 16px/400 | The note is P0 content (UXT-011). At 14px a multi-line note is not readable at board distance. 16px is the base Body size, so no new step. |
