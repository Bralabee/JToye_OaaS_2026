<objective>
When the kitchen tablet's session lapses or access ends, the board must stop loudly instead of quietly becoming a sign-in page
(D-14, D-08 on the kitchen; RWO-021 UXT-021, RWO-003).

Purpose: a board that silently turns into a sign-in page misses every order of a Friday rush. The fix is an overlay that cannot be
mistaken for a working board, an alarm distinct from the new-order chime, a safe return path to the kitchen, and a silent token
refresh so the overlay means a real lapse.

Output: the cancellable lapse event, KdsBoardStopped, the alarm pattern, the validated callbackUrl, the silent refresh, the live spec.
</objective>
