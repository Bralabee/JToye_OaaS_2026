| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-37-24 | Information Disclosure | token leaking via Referer or third-party loads | medium | mitigate | Referrer-Policy no-referrer on /invite, no third-party resources, replaceState drops the token, header snapshot pinned |
| T-37-25 | Information Disclosure | token in frontend access logs (path segment) | low | accept | UI-SPEC fixes the route shape; single-use, 72h TTL and digest-only storage bound the exposure; recorded residual |
| T-37-26 | Information Disclosure | password persisted or echoed client-side | high | mitigate | Component state only; storage spy asserts zero writes; error copy never interpolates the value |
| T-37-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installed |
</threat_model>
