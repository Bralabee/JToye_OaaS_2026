<objective>
Turn an invite link into an account that lands with exactly the invited grant (D-07, D-26; RWO-004, RWO-003).

Purpose: the vendor realm disallows self-registration, so core creates the Keycloak user itself with the password the invitee
chose on our page, declares tenant_id admin-only so the token carries a tenant, and writes the grant and directory row in the
pinned tenant. Every unusable-link cause looks the same from outside.

Output: KeycloakAdminClient.createUser (+ by-content tests), the realm user-profile change, the public preview/accept endpoints,
three typed exceptions, the accept IT.
</objective>
