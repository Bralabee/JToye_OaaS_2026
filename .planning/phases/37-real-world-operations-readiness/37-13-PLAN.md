<objective>
Import a menu into the shop the vendor chose, and copy a menu between shops without losing allergen data (RWO-026 UXT-026).

Purpose: CSV import ignores the selected shop and creates shop-less products no storefront shows; there is no way to copy a menu.
Both go through the domain service every writer uses (theme 6).

Output: the CSV shopId default, the copy endpoint, their ITs, the OpenAPI snapshot.
</objective>

<feature>
  <name>CSV target shop and copy-to-shop</name>
  <files>ProductController, BulkImportService, ProductService, CopyProductsRequest, CopyProductsResult</files>
  <behavior>
    - CSV of 3 rows without shop_id + ?shopId=A (manager of A) -> 3 products with shop_id A, visible on A's storefront products endpoint
    - same CSV with no shopId -> 3 per-row errors "shop required", 0 created
    - ?shopId=B where the caller manages only A -> 403
    - copy A->B (manager of both) of 2 products -> created 2; each copy's allergen_mask, allergen_spans, may_contain_mask, ingredients_text, vat_rate equal the source by SQL; media links point at the same asset ids
    - same copy again -> created 0, skipped 2
    - copy to a shop the caller does not manage -> 403
  </behavior>
  <implementation>Thread an optional default shop into BulkImportService; copy builds a CreateProductRequest from each source product.</implementation>
</feature>
