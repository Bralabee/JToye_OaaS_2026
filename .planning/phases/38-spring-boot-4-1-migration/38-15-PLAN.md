<objective>
Prove the CVE floors on the Boot-4 lines and run the image gate locally before anything is pushed.

Purpose: the Trivy image gate lives in build-and-push, which runs on push and release only, so a
dependency regression merges green and turns main red afterwards; this repo's pin comments record
exactly that history. Boot 4 also changed what the pin KEYS mean (jackson-bom.version now moves
Jackson 3), so each key must be proven by dependencyInsight and a near-miss arm, as the existing
comments demand of any PR that touches them.

Output: a clean local Trivy scan of the final image (with main's scan and the DB timestamp beside
it), per-pin resolution proofs with arms, and rewritten pin comments.
</objective>
