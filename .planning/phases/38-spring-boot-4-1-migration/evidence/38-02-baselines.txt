=== D-05 premise, as measured
D-05 (owner, 2026-10-04) says a 404 on this path "matches Boot 3.5 behaviour today". Measured, that
is HALF-TRUE: Boot 3.5.16 answers 404 errors/not-found only to an AUTHENTICATED caller. An
UNAUTHENTICATED caller gets 401 errors/unauthorized with WWW-Authenticate: Bearer, because the path
is unmapped and falls to anyRequest().authenticated(). 38-06 still implements the locked 404 for EVERY
caller (D-05 is a ruling, not a parity claim), so for an anonymous caller the answer CHANGES from 401
to 404. This baseline is the record of that change; the two _boot35Baseline methods are expected to
go red on Boot 4 until 38-06 updates them deliberately.
