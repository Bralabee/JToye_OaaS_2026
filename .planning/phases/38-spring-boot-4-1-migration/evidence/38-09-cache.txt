1. What the Spring Data Redis 4.1.1 builder does (javap -c of the cached jar, not the docs)
   GenericJacksonJsonRedisSerializerBuilder.build(), when enableDefaultTyping(ptv) was called:
     new GenericJacksonJsonRedisSerializer$TypeResolverBuilder(ptv, DefaultTyping.NON_FINAL,
         JsonTypeInfo.As.PROPERTY, JsonTypeInfo.Id.CLASS, typePropertyName)
     configure(FAIL_ON_MISSING_EXTERNAL_TYPE_ID_PROPERTY, false); configure(FAIL_ON_UNKNOWN_PROPERTIES, false)
     setDefaultTyping(<that builder>)
   So the typing scheme is NON_FINAL (Spring's resolver), not Jackson-2's EVERYTHING, which Jackson 3
   removed. The ids written therefore change, and the allowlist has to be re-derived from bytes.
   The builder also offers enableUnsafeDefaultTyping(); it is not used (SEC-4).
