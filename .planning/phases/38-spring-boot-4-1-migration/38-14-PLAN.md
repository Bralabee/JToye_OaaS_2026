<objective>
Accept springdoc 3.1.1's contract changes the way docs/api/README.md prescribes (regenerate the
snapshot in the same PR) and only after proving each newly required field was already enforced.

Purpose: the spike measured 19 changed schemas: 11 request DTOs gained `required`, 5 fields gained
`format: email`, the HttpStatus enum lost deprecated constants, one field became nullable. Newly
required fields look like a breaking change to consumers; CONTEXT allows accepting them only where
the server already rejected the request without them. 38-02 measured that set on Boot 3.5.

Output: the regenerated snapshot, a subset proof against the 3.5 inventory, the explained remainder,
the breaking-change gate run locally both ways, and the consumers green.
</objective>
