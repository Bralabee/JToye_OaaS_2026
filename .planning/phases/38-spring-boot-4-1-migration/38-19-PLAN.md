- Boot's bean: tools.jackson.databind.json.JsonMapper. Local mappers are immutable and built with JsonMapper.builder(): features
  are enabled on the builder, then build().
- tools.jackson.databind.JsonNode, and ObjectNode / ArrayNode in tools.jackson.databind.node.
- tools.jackson.core.JacksonException is unchecked and replaces the checked processing exception.
- tools.jackson.core.type.TypeReference.

  tools.jackson.databind.cfg.DateTimeFeature; java.time support is built in (no module registration).

  elements() -> values(). asText() still exists; prefer asString().
