# Phase 38 Plan 14: OpenAPI Snapshot on springdoc 3.1.1 Summary

**The OpenAPI snapshot is regenerated on Boot 4.1.1 / springdoc 3.1.1 and accepted with per-field evidence. springdoc 3 now documents `@NotBlank`/`@NotEmpty` as `required`. The 18 newly required fields, across 11 request DTOs, are exactly the inventory's `@NotBlank`/`@NotEmpty` pairs that 3.5 did not document; 38-02 measured each one as already rejected with a 400 on Boot 3.5. Everything else in the diff documents behaviour the server already had. That covers `format: email` on `@Email` fields, `exclusiveMinimum` from an existing `@Positive` (enforcement measured), and an explicit `nullable`. It also covers Spring Framework 7's own HttpStatus enum and the JDK-reflection schemas behind the `GET /` redirect. The CI gate is green on the new snapshot and red on the old one, the edge and MCP consumers are green, and the full integration suite is 771/0. The phase ledger has no red left.**
