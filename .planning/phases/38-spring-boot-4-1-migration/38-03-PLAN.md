<assumption_delta_decision>
The detector fired on "also" (the ROADMAP's "the move also unblocks springdoc 3.1.1"), a wording
false positive. The genuine pluralisation this phase introduces is a SECOND JSON library on the
classpath: Jackson 3 (tools.jackson) arrives as Boot 4's default while Jackson 2 stays for
transitive users (springdoc's swagger-core, the Azure SDK, Stripe).

- Primary noun: the application JSON mapper. Decision: PROMOTE. Jackson 3's JsonMapper becomes the
  only mapper main code may use (D-01); Jackson 2 is demoted to a transitive-only dependency with a
  CVE floor and no main-code import. The interim Jackson-2 bean in this plan is a dated bridge with
  a named removal plan (38-12), not an add-alongside.
- Invariant test (accepted, delivered by 38-12): a permanent contract test fails if any main-code
  file imports Jackson-2 databind/core or if the Jackson-2 auto-configuration module returns to the
  production runtime classpath.
</assumption_delta_decision>
