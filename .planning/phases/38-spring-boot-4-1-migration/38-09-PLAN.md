<objective>
Move the Redis cache to Jackson 3 without reopening SEC-4, and make Jackson-2-era cache entries
unreachable by key rather than relying on a silently swallowed read error.

Purpose: Jackson 3 removed DefaultTyping.EVERYTHING, so the set of type ids written changes and the
allowlist (derived in QA-council SEC-4 from LIVE bytes) must be re-derived the same way. An
incompatible old entry today is a permanent silent cache miss (RedisCacheErrorHandler swallows GET
errors); a versioned key prefix turns "hope it self-heals" into "never read, expires by TTL".

Output: CacheConfig on GenericJacksonJsonRedisSerializer with a re-derived validator and a v4:
key prefix, the two serializer tests updated, and a real-Redis isolation test.
</objective>
