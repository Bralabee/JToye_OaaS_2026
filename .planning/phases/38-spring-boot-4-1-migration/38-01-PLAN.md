<objective>
Capture, on the CURRENT Boot 3.5.16 / Jackson 2 tree, every serialized shape that persisted or
in-flight state carries across the Boot 4 deploy, so later plans can prove Jackson 3 reads them
and (where the shape is a hash) reproduces them.

Purpose: D-01's hazard ("a cached value or a queued message written in the Jackson-2 shape must
still be readable after the switch") and BOOT4-08's idempotency continuity can only be proven
against bytes the OLD code actually wrote. Once any Jackson-3 change lands those bytes can no
longer be produced from this tree, which is why this plan is Wave 1 and touches nothing but tests.

Output: a Jackson-free GoldenSamples factory, the fixture tree under
core-java/src/test/resources/jackson2-golden with a MANIFEST, a permanent integrity test, and a
README recording the capture commit. The one-shot generator is deleted after its output is
committed.
</objective>
