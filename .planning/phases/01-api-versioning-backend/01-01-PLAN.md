<threat_model>
## Threat Model (ASVS Level 1)

### Threats Assessed
1. **Path bypass via old unversioned URLs** -- MEDIUM severity
   - Risk: If old paths still resolve, unauthenticated access patterns may differ
   - Mitigation: addPathPrefix moves controller mappings entirely; old paths return 404. SecurityConfig `anyRequest().authenticated()` covers all new `/api/v1/**` paths. Tests verify old paths return 404.

2. **Webhook path accidentally versioned** -- HIGH severity (blocked)
   - Risk: Stripe webhook at `/public/payments` stops receiving callbacks if moved to `/api/v1/public/payments`
   - Mitigation: Package-based predicate explicitly lists only 7 versioned packages (per D-01, D-03). PaymentController in `uk.jtoye.core.payment` is NOT in the predicate list. Test verifies `/public/**` remains accessible.

3. **Health endpoint moved, breaking container orchestration** -- HIGH severity (blocked)
   - Risk: Docker/K8s health probes fail if `/health` moves to `/api/v1/health`
   - Mitigation: CoreApplication.java (root package `uk.jtoye.core`) and SecurityHealthController (`uk.jtoye.core.controller`) are NOT in the predicate. Test verifies `/health` returns 200.

### Verdict: PASS -- Both HIGH threats mitigated by positive-list predicate design.
</threat_model>
