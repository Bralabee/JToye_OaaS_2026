Seven consecutive MISSING results are exactly what a broken detector produces — a typo in the loop,
a `command -v` that always fails, a PATH that resolves nothing. The control runs the identical
construct against four tools that ARE installed and prints their real paths, proving the detector
discriminates. It also establishes the remedy is available locally: go 1.26.5 is present and

is a viable install path with no new system dependency. `hey` is confirmed absent from that
directory listing, so the MISSING result is not a PATH-ordering artefact.
