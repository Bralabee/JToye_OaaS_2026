## Threat Model (ASVS Level 1)

| Threat | Severity | Mitigation |
|--------|----------|------------|
| XSS via promotion label/announcement body | MEDIUM | React JSX auto-escapes rendered strings. No dangerouslySetInnerHTML used. |
| CSRF on CRUD operations | LOW | JWT Bearer token in Authorization header (not cookie-based auth). apiClient attaches token per request. |
| Cross-tenant data access | LOW (frontend only) | Backend enforces RLS via TenantContext. Frontend cannot bypass — all requests go through authenticated apiClient. |
| Stale JWT on long sessions | LOW | apiClient interceptor redirects to /auth/signin on 401. |

No HIGH severity threats. All data flows through the existing authenticated apiClient which attaches JWT tokens. The backend (Phase 3) already enforces RLS on all promotion/announcement endpoints.
