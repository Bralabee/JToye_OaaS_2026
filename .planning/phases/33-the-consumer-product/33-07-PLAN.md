THREE STATES, THREE HEADINGS. The heading is derived from state, never hardcoded:
  no coordinate (server default, AND after denial)  -> the location-free heading 33-03 chose
  coordinate held, results found                    -> a "near you" phrasing
  coordinate held, nothing within radius            -> explicit "nothing within {r} km — here is
                                                       everything on J'Toye", falling back to the
                                                       unlocated list
The third state is not optional: silently showing the full list under a "near you" heading when nothing
is near is the same class of lie #544 exists to stop.

DO NOT PERSIST THE COORDINATE. Precise geolocation is personal data under UK GDPR; a cookie is sent on
every matched request; and **#116's cookie banner has not shipped** (Phase 31, LGL-01). Writing a
location cookie now creates a PECR consent question this phase cannot close. React state ONLY — not
`localStorage`, and `sessionStorage` only if the owner explicitly accepts the PECR "strictly necessary
for a service the user requested" argument. State-only sidesteps it entirely.

BROWSER MECHANICS THAT MUST BE IN THE CODE:
  - Secure context required. `http://localhost:3000` IS a secure context, so local dev and Playwright
    work. Any plain-http NON-localhost host silently yields no location.
  - `Permissions-Policy: geolocation=(self)` — fixed in `33-03`. **VERIFY it on the live response before
    debugging anything else**: with the pre-33-03 empty allowlist the API is denied before any prompt and
    presents identically to a user denial.
  - Gesture-gate the prompt. Calling `getCurrentPosition()` during render or on mount fires an
    unsolicited permission prompt on first paint, which browsers penalise and users read as hostile.
  - Handle all THREE failures — PERMISSION_DENIED, POSITION_UNAVAILABLE, TIMEOUT — with the same fallback
    as "never asked". A user who denies must not see a spinner.

PLAYWRIGHT SUPPORT, UNUSED IN THIS REPO SO FAR (verified: the geolocation alternation over
`playwright.config.ts` and `e2e/` returns RC=1; control returns 22 files):
  context.grantPermissions(['geolocation'])
  context.setGeolocation({ latitude, longitude })
This makes the located path DETERMINISTIC — no real GPS, no flake, both directions testable.
