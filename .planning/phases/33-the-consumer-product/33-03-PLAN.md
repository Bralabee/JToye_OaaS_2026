## Instrument notes

- **Never `grep -c X f | grep -qx 0`** — `grep -c` exits 1 on the DESIRED (zero) state and the hook
  blocks the shape. Use `out=$(grep -c X f || true); grep -qx 0 <<< "$out"`.
- **Rebuild before E2E.** `next.config.mjs` headers are baked at build time; `docker compose start`
  does not rebuild. Prove parity by content, not by HTTP 200, and run the freshness gate from the main
  checkout.
- Use `getByRole` for every heading assertion (streaming staging buffer, #556/#593).

- A screenshot cannot verify motion, and one taken without scrolling reads `Reveal` sections as empty
  bands.
- `grep` is **ugrep** — use `-F` for literals with braces/parens, `-E` for alternation.
