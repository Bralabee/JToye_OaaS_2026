# Sketch 007: The Pass — Full Page

## Design Question

006-A won as a hero direction; the owner asked for "plenty of design content and
elegance enhancements". This sketch elaborates the language into a complete page
and extends its signature: *the pass* is where kitchen tickets live, so the
order-ticket (receipt stub, perforated top, ticket number) becomes the page's
recurring object.

## How to View

open .planning/sketches/007-the-pass-full-page/index.html

## Page anatomy (top to bottom)

1. Hero scene — diagonal slab, interlocked type × plate, search + crawlable cuisine
   chips, rubber-stamp trust markers.
2. Dish strip — varied-size cards breaking the scene edge, now with cuisine/area
   meta + live dot.
3. Amber marquee band.
4. **How it works as three order tickets** (perforated stubs, ticket numbers,
   dashed rail) — the signature extension.
5. Tonight's kitchens — asymmetric showcase (1 large + 2 stacked), FHRS pill +
   "open now" glow on the photo, gradient veil for text legibility.
6. Customer quote on a diagonal-clipped oxblood slab.
7. Stats — three huge numerals.
8. Operator section — angled two-tone ground, benefits list, gold CTA, and a
   stylised **KDS ticket** ("Incoming · № 0250 … Mark ready") with a "live in a
   day" stamp.
9. Typographic doors + full four-column footer with legal line.

## Verified

390 / 768 / 1280 / 1920, zero horizontal scroll, all 9 images loading with
gradient+emoji fallbacks. Shadows/radii/spacing on a 3-level token system.
