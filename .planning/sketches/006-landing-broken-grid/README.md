# Sketch 006: Landing, Structure Broken Open

## Design Question

Sketch 005 varied the skin (photography/sticker/dark/motion) but kept the stacked
hero→cards→steps→CTA skeleton, and the owner rejected all four. This sketch broke
the STRUCTURE instead, three ways, all inside the locked brand (oxblood #3A0B0D +
Work Sans + amber; --primary orange-700).

## How to View

open .planning/sketches/006-landing-broken-grid/index.html

## Variants

- **A: The Pass** ★ WINNER — one composed scene: diagonal oxblood slab, 12vw display
  type with an amber-outlined word, a dish plate breaking the frame, rubber-stamp
  trust markers, varied-size cards overlapping the scene edge, typographic doors.
- **B: Menu Board** — no hero; the landing is a numbered cuisine board in huge type;
  hover floods a row amber and a dish plate springs in.
- **C: Table Collage** — free canvas: headline fragments interleaved with photos laid
  like plates on a table, stickers pinned to dishes, diagonal marquee, torn edge.

## Verdict & lesson (2026-08-31)

Owner picked **A** ("looking more like a good candidate"), asking for more design
content + elegance — elaborated as sketch 007. Round 1 of this sketch shipped
"extremely malformed" at desktop because it used absolute vh-positioning verified
only at 390px. The rebuild that won is the round-2 system: composition capped at
the 1280 marketing tier (grounds full-bleed), 12-col grid with deliberate track
overlap instead of absolute positioning, stickers/notes anchored to their photos,
and EVERY round verified at 390/768/1280/1920 before handover. That verification
rule is non-negotiable for all future sketches.
